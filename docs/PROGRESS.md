# Tiến độ Chương I

Đã triển khai mã nguồn độc lập, 3 tầng và làng, các cơ chế chính, giao diện cảm ứng, bài kiểm thử và hướng dẫn GitHub. Review đã xử lý 3 vấn đề đầu vào/menu và kiểm tra bản lưu. Giới hạn QA được ghi ở QA.md. Không sửa dự án PixelWorld, chưa xuất bản lên GitHub hay App Store.

Tiếp theo: kiểm thử iPhone thật → cân bằng bản 3 tầng → bổ sung bản đồ/động vật/hoạt ảnh → phát triển tầng 4–10 và cốt truyện. Giữ bản lưu tương thích hoặc bổ sung migration khi thay đổi schema.
